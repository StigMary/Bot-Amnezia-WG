# 🚀 KJZNNETx VPN Telegram Bot & WebApp 2.0

Современная многосерверная панель управления VPN-сетью (**AmneziaWG**, **Xray Reality / Dokodemo**, **WireGuard**) с интеграцией в Telegram Mini Apps (WebApp), умной системой биллинга, контролем сессий и шейпером скорости (QoS).

---

## 🌟 Основные возможности

* 📱 **Интерактивный WebApp Дашборд:** Графика нагрузки серверов (CPU, RAM, диск, сеть в реальном времени), детальная статистика по абонентам, управление ключами и тарифами в 1 клик.
* 🌐 **Многосерверная архитектура (SE + RU):** Поддержка локальных и удалённых нод через защищённые SSH ControlMaster соединения.
* ⚡ **Точный шейпер скорости (QoS):** Аппаратный шейпинг трафика через Linux `tc` (HTB для Egress/Download и Ingress policing для Upload) — жесткое соблюдение выбранного тарифа (10 / 30 / 50 / 100 Мбит/с).
* 🔄 **Автоматическая синхронизация имён:** Чтение `/opt/amnezia/awg/clientsTable` и автоматическая подгрузка имён клиентов, созданных в приложении Amnezia.
* 💳 **Биллинг и уведомления:** Учёт сроков подписки, автонапоминания клиентам об оплате и возможность временной блокировки/ограничения скорости.
* 🛡️ **Безопасность:** Авторизация администратора через Telegram `initData` (HMAC-SHA256) + проверка прав по Telegram ID. Все чувствительные данные изолированы в `.env` и не попадают в репозиторий.

## 🛠️ Быстрая установка (1 команда)

### 1. Клонирование репозитория
```bash
git clone https://github.com/StigMary/Bot-Amnezia-WG.git /opt/vpn_bot
cd /opt/vpn_bot
```

### 2. Запуск автоматического установщика
```bash
chmod +x install.sh update.sh
./install.sh
```
*Скрипт сам создаст виртуальное окружение `.venv`, установит библиотеки, подготовит папки и зарегистрирует системные службы `vpn-bot` и `vpn-webapp`.*

### 3. Настройка конфигурации
Отредактируйте созданный файл `.env`:
```bash
nano .env
```
Укажите ваш `BOT_TOKEN` и `ADMIN_ID`.

### 4. Запуск служб
```bash
sudo systemctl restart vpn-bot vpn-webapp
```

## 🔄 Обновление бота

Для обновления бота на сервере до последней версии из репозитория достаточно запустить:
```bash
cd /opt/vpn_bot
./update.sh
```
*Скрипт автоматически скачает свежие коммиты (`git pull`), проверит зависимости и мягко перезапустит службы.*

## 📋 Управление службами (Systemd)

| Действие | Команда |
| :--- | :--- |
| **Статус бота:** | `sudo systemctl status vpn-bot` |
| **Статус веб-панели:** | `sudo systemctl status vpn-webapp` |
| **Логи бота в реальном времени:** | `journalctl -u vpn-bot -f` |
| **Логи веб-панели:** | `journalctl -u vpn-webapp -f` |
| **Перезапуск всех сервисов:** | `sudo systemctl restart vpn-bot vpn-webapp` |
